### Specialties

- Hauling bricks in the cloud, rolling around in Kubernetes, getting lost in the Azure Portal
- Fixing broken systems until they look unbroken
- Using Clean Architecture and SDD to make simple problems sound profound
- Directing an AI to write code, then wiping up after it
- Producing YAML. Vast quantities of YAML.

### Lately

Face-first into agentic coding: vibe-coding through a project so I can watch an AI
wreck it in a tone of total confidence, then clean up the mess by hand.

A committed believer in SDD — once the spec is written clearly enough, the blame can
be transferred to the spec with a completely clean conscience.

### A few things I'm stubborn about

- Static if it can be static; if the free tier fits, I'm not running a server
- Tools that get out of the way — `bun`, `uv`, `just`. No install step I have to
  explain twice.
- Anything I'd rather not have to take on faith gets written as a pure function with tests
- If I can't see what it's doing, it doesn't count as working
- If an agent built it, post the bill too

### Interests

- Attaining philosophical insight through debugging. Current insight: life doesn't come

### Whereabouts

### 近期

再親自收拾它們的爛攤子。

- 爬山，已達成 2026 臺北大縱走
